# Archive — Documentation historique

Ce dossier contient les fichiers markdown historiques du projet, issus des phases précédentes de développement avec Cursor.

## Organisation

| Dossier | Contenu |
|---------|---------|
| `analyses/` | Analyses stratégiques et architecturales du projet |
| `ameliorations/` | Notes sur les améliorations successives |
| `modules/` | Documentation des modules (Odoo, paie, comptabilité...) |
| `plans/` | Plans de projet, roadmap, quick start |
| `guides/` | Guides utilisateur, démarrage, tests |
| `rapports/` | Rapports de tests, statuts, progression |
| `integration/` | Notes d'intégration Odoo, migrations, refonte |
| `implementation/` | Documentation d'implémentation et contrôleurs |
| `checklists/` | Checklists projet, déploiement, données |
| `resumes/` | Résumés de sessions et sprints |
| `verification/` | Documents de vérification système et routes |
| `divers/` | Autres documents (commandes, fonctionnalités, patterns) |
| `erp-all-by-fouta-legacy/` | Snapshots initiaux du projet : prototypes HTML/TSX, Excel sources, PDFs |

## Note

Ces documents reflètent l'état du projet à différents moments historiques. Pour la documentation à jour, voir :
- `README.md` à la racine du projet
- `docs/DOCUMENTATION_API.md` pour l'API
- `docs/ERP_MODULES_COMPLETION_STATUS.md` pour l'état des modules
