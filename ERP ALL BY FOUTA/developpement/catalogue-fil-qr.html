📚 Catalogue Professionnel de Fils - La Plume Artisanale

Format recommandé : PNG ou SVG transparent, ratio ~3:1

📌 Instructions d'utilisation :
  1. Logo (optionnel) : Chargez votre logo PNG, JPG ou SVG. Format recommandé : largeur ~3 fois la hauteur, fond transparent.
  2. Fichier Excel : Chargez votre fichier contenant : Code Commercial (C01, C02...), Couleur Commercial (BLANC, ROUGE, BEIGE, BLEU...), Numéro/Métrique, Couleur, Code Fabrication MP, Num de Lot
  3. Couleur Commercial : Ajoutez cette colonne dans votre Excel pour définir la famille de couleur (BLANC, ROUGE, BEIGE, BLEU, VERT, GRIS, ROSE, JAUNE, ORANGE, VIOLET, MARRON, NOIR, TURQUOISE, KAKI, BORDEAUX, TAUPE, CORAIL, MARINE, FUSCHIA, LILA, NAVY, NATUREL, ECRU, PRALINE). Si la colonne est absente, la couleur du fil sera utilisée.
  4. Les fils sont automatiquement triés par : N° de Lot (du plus ancien au plus récent) → N° Métrique → Code Fabrication
  5. Le logo occupera 1/3 de la largeur avec une hauteur compacte (max 80px)
  6. Format A4 optimisé : Marge gauche de 2 cm pour perforation classeur
